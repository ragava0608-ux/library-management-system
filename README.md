# library-management-system
A Java-based Library Management System to manage books, track book availability, and handle issuing and returning books efficiently.
## Problem Statement
Managing library books manually can be time-consuming and difficult. The Library Management System is a Java-based application designed to simplify library operations, including adding books, viewing available books, issuing books, and returning books.

## Technologies Used
- Java
- JDK
- Eclipse IDE

## How to Compile and Run

### Prerequisites
- Install the Java Development Kit (JDK).
- Install an IDE such as Eclipse or use the command prompt.

### Using Command Prompt
1. Clone the repository:
   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```
2. Navigate to the project folder.
3. Compile the Java file:
   ```bash
   javac Main.java
   ```
4. Run the program:
   ```bash
   java Main
   ```

**Note:** Replace `Main.java` with your actual Java file name if it is different.

## Features
- Add new books.
- Display available books.
- Issue books.
- Return books.
